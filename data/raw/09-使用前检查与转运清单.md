# 使用前检查与转运清单

清单的价值不在"有没有"，在**够不够短**。一张三十项的清单没有人逐条看，
等于没有清单。所以下面几张每张都控制在十项以内，并且只保留那些
**漏掉之后后果严重**的项目。

这些清单是经验整理（依据等级 C），具体条目应当结合本院制度增删。
标注 `[1]` 的条目直接来自 FDA 的建议。

## 一、上泵前（每次）

1. **耗材匹配**：管路是否是这台泵的配套型号；注射泵的话，泵内选择的注射器规格
   和实际装的是不是同一种。
2. **管路完全卡入固定夹**后再关门。这一步没做会导致管路被夹瘪、输注不足 `[1]`。
3. **排气完成**，管路里看不到气泡，接头已拧紧。
4. **泵门关严、锁扣到位**，门体和外壳没有裂纹（细小的也算 `[1]`）。
5. **电池电量足够**，或已接市电。
6. **报警音量在可听位置**。这一条最常被跳过，但它正是"报警响了没人知道"
   这类事故的根源。
7. 设置参数后，**看屏幕核对数值和单位**，不要凭按键次数判断。

## 二、高危药品加做

1. 按**独立双人核对**执行：两人各自单独算、单独看屏幕，再比对结论 `[1]`。
   两个人站在一起看同一块屏幕不算独立。
2. 核对顺序建议：**体重和单位 → 浓度 → 速率**。
   先对最容易出错、又最不容易被发现的单位。
3. 有药物库的启用药物库，弹出的警示当场读一遍再决定 `[1]`。
4. 挂一个独立于泵的容量核对手段（时间条或量液器）`[1]`。

## 三、转运前

1. 确认电量，按转运时长留余量。
2. 备用方案明确：转运途中泵故障，药和管路怎么处理、找谁。
3. 对容量负荷敏感的患者，预案里要写明**先夹闭再处理** `[1]`。
4. 报警音量再次确认 —— 转运环境比病房吵得多。
5. 参数抄一份带在转运单上：药名、浓度、速率、已输量。到目的地后按单核对，
   不要凭记忆复述。

## 四、转运到达后

1. 按**转运单**逐项核对泵上的设置，而不是"看一眼差不多"。
2. 重新接市电。
3. 管路检查：转运过程中有没有受压、打折、脱开。
4. 记录到达时间和已输量，作为后续核对流速的基线。

## 五、交接班

FDA 特别把交接班列为必须重新核对泵参数的时机 `[1]`。建议交接时
**只对三个数**：药名和浓度、当前速率、已输量。这三个数对了，
其他问题基本都能在过程中发现；这三个数没对，后面的核对都是在错的基础上做。

## 清单怎么用

两张建议：

- **贴在泵车上**而不是贴在墙上。清单离动作现场越远，执行率越低。
- 每隔一段时间**实际观察**一次执行情况，而不是靠签字。签字可以补，
观察补不了。这是管理经验，不是标准要求。
