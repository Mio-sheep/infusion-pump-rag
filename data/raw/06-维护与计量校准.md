# 维护与计量校准

维护这一块的价值不在"多做"，在"做对项目"。一台泵的外观擦得很干净，
但气泡传感器已经失灵、报警不响 —— 这台泵在质控记录上是合格的，
在临床上是危险的。所以维护清单要围绕**功能**，不是围绕外观。

## 日常维护：清洁

清洁是维护里最容易被想当然的一项。FDA 明确记录过：使用者认为可以接受的
清洁方式，反而会损坏泵，让它在临床上不可靠 `[3]`。

要点只有一条：**按厂家说明书允许的清洁剂和方式来**。不要凭经验选消毒剂，
不要让液体从按键缝隙渗进去（有胰岛素泵因按键间裂纹进水而故障的记录 `[3]`）。

## 电池管理

- 按厂家推荐的寿命周期更换，不要等它不耐用才换。
- 外观检查看两处：**鼓包**和**外壳接缝开裂**。密封铅酸电池过充损坏的典型表现
  就是这两样 `[3]`。
- 长期插着市电不代表电池是好的，需要按厂家要求做周期性的充放电维护。
- 转运前确认电量。这一条的实际执行率取决于它有没有进交接班清单。

## 预防性维护该查什么

下面这张表是经验整理，不是标准条文。具体的检测限值以厂家技术指标和
现行标准文本为准。

| 项目 | 查什么 |
| --- | --- |
| 外观与机械 | 门、锁扣、铰链、卡槽、推杆的磨损与裂纹 |
| 流量准确性 | 几个典型流量点的实际输注量 |
| 报警功能 | 气泡、阻塞、电池欠压、门未关的触发，以及**报警声能不能听到** |
| 传感器 | 气泡、压力传感器的灵敏度和清洁度 |
| 电气安全 | 保护接地、漏电流（按电气安全通用要求做） |
| 软件 | 固件版本核对，按厂家公告升级 |
| 电池 | 续航测试，到期更换 |

**报警声能不能听到**这一项最容易被省略，因为它看起来不像一项"检测"。
但前面讲过，报警音量被调低导致的失效是完全真实的失效模式。
建议的做法是把泵调到报警状态，站在科室走廊正常距离听一下。

## 流量校准

国内对医用注射泵和输液泵做计量校准的主要依据是
JJF 1259-2010《医用注射泵和输液泵校准规范》`[1]`。
部分地区另有地方计量规程，使用时要确认本地区现行有效的版本。

校准的基本思路：

1. 选定几个有代表性的流量点（通常覆盖常用工作区间）；
2. 用标准器测实际输出 —— 常见做法是称重法（天平称量输出的质量，
   换算成体积），或者用专用的输液泵检测仪直接读；
3. 比对设定值和实测值，得到误差；
4. 记录测量不确定度。

**具体限值我不在这里写。** 原因有两个：一是规范会换版，二是不同流速点、
不同机型适用的判定条件不一样。写一个脱离条件的数字比不写更糟。
要用的请直接查现行规范文本 `[1]`。

测量不确定度的主要来源：天平、计时器、温度（液体密度随温度变）、
蒸发损失、管路与注射器自身的一致性。检测前让设备在稳定环境温度下
预运行一段时间，避免初始阶段的流量波动污染结果。

标准 `[2]` 里对阻塞解除后的团注量也有试验要求 —— 这一项和临床风险直接相关，
是值得关注的检测项。

## 不合格怎么处理

停用 → 挂标签 → 隔离 → 报修或校准 → 复检合格后才能回临床。

这一条流程的价值在于"隔离"两个字。超差的设备如果只是"报修"但还留在科室，
被拿去用的概率不低。

## 台账要留什么

- 设备台账：型号、序列号、购置和启用日期、所在科室
- 维修记录：故障现象、报警代码、更换部件
- 预防性维护记录：日期、项目、结果、下次到期日
- 计量校准记录：依据的规程、所用标准器及其有效期、检测点、误差、不确定度
- 电池更换记录
- 不良事件与上报记录
- 人员培训记录

标准器和它的有效期经常被漏记。**用超期的标准器做校准，整套数据都是无效的。**
