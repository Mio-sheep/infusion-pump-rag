# 术语表、标准与法规速查

> 资料来源：FDA 输液泵术语表、公开标准信息整理

## 1. 中英术语对照

| 中文 | 英文 | 说明 |
| --- | --- | --- |
| 输液泵 | infusion pump | 以受控方式将液体输入患者体内的医疗器械 |
| 注射泵 | syringe pump / syringe infusion pump | 以活塞式注射器作为储液器并控制输液的泵 |
| 弹性泵 | elastomeric infusion pump | 利用弹性膜的弹力提供输注动力 |
| 肠内营养泵 | enteral infusion pump | 向消化道输送液体营养液与药物 |
| 胰岛素泵 | insulin infusion pump | 便携式机电泵，多用于糖尿病居家治疗 |
| 患者自控镇痛泵 | PCA pump (patient-controlled analgesia) | 允许患者按需追加**限量**镇痛药 |
| 多通道泵 | multi-channel pump | 可从多个储液器以不同速率输注 |
| 智能泵 | smart pump | 带用药防错软件，超限时报警 |
| 药物库 | drug library / DERS | 预设安全限值参数集 |
| 过量输注 | over-infusion | 实际输注量多于预期 |
| 输注不足 | under-infusion | 实际输注量少于预期 |
| 阻塞报警 | occlusion alarm | 管路阻力升高的报警 |
| 阻塞解除后团注 | bolus after occlusion release | 阻塞解除瞬间的一次性额外输注 |
| 气泡报警 | air-in-line alarm | 管路内空气检测报警 |
| 按键连击 | key bounce | 一次按键被识别为多次 |
| 假报警 | nuisance alarm | 无实际问题的干扰性报警 |
| 独立双人核对 | independent double-check | 两人各自单独核对后比对结果 |
| 五个正确 | the 5 rights | 正确患者/药物/剂量/途径/时间 |
| 使用错误 | use error | 未实现安全有效使用的情形 |
| 人因/人机工程 | human factors (HF) | 研究人如何使用技术及其与环境的交互 |
| 待输容量 | VTBI (volume to be infused) | 计划输注的容量 |
| 便携式输液泵 | ambulatory infusion pump | 可携带或可穿戴 |
| 召回 | recall | 因缺陷或潜在危害而撤市或纠正 |
| 不良事件 | adverse event | 与器械使用相关的不良体验 |

## 2. 常用参数与单位

| 参数 | 常见单位 | 备注 |
| --- | --- | --- |
| 流速 | mL/h、mL/min | 最常用 |
| 剂量速率 | mg/kg/h、μg/kg/min、U/h | 依赖体重与浓度，**极易出错** |
| 待输容量 VTBI | mL | 设定输注总量 |
| 阻塞压力阈值 | mmHg、kPa、1~3 档（低/中/高） | 阈值越低越早报警 |
| 体重 | kg | **注意部分泵要求 kg，误按磅输入会造成剂量错误** |
| 药液浓度 | mg/mL、U/mL、% | 计算速率的前提 |

### 速率换算示例

若医嘱为 `0.1 μg/kg/min`，患者体重 `60 kg`，药液浓度 `4 mg/50 mL`（即 80 μg/mL）：

```
每小时所需药量 = 0.1 μg/kg/min × 60 kg × 60 min = 360 μg/h
所需流速       = 360 μg/h ÷ 80 μg/mL        = 4.5 mL/h
```

> 计算务必双人核对；不同医院对同一种药的配置浓度不同，不可套用其他单位的经验值。

| JJF 1259-2010 | 医用注射泵和输液泵校准规范 | 国内输液泵/注射泵**计量校准**的主要依据 |
| YY 9706.227（系列） | 医用电气设备 第2-24部分：输液泵和输液控制器的专用要求 | 对应 IEC 60601-2-24，规定流量准确度、报警、阻塞解除后团注等 |

### 3.3 美国 FDA 监管术语

- **510(k)**：上市前通知，证明与已合法上市器械"实质等同（substantially equivalent）"。
- **PMA**：上市前批准，适用于 Class III 器械。
- **MAUDE**：制造商与用户设施器械经验数据库。
- **TPLC**：Total Product Life Cycle，全生命周期监管框架。
- **Recall**：召回。

## 4. 不良事件上报

- **中国**：按《医疗器械不良事件监测和再评价管理办法》，通过国家医疗器械不良事件监测信息系统上报。医疗机构为上报主体之一。
- **美国**：向 FDA 通过 MedWatch 自愿上报；死亡/严重伤害事件由使用机构按制度上报。
- 注意：上报时**不影响患者隐私保护要求**；FDA 明确说明向 FDA 提交报告**不受 HIPAA 限制**。

## 5. 速查：三条最容易踩的坑

1. **单位/体重输入错误**：磅 vs 千克、mL/h vs mg/kg/h，是最常见的十倍级差错来源。
2. **耗材不配套**：蠕动泵必须用专用管路，注射泵必须选择与实物一致的注射器规格，否则精度无从谈起。
3. **"能开机 = 没问题"**：传感器失效、软件缺陷、报警不响都不会阻止泵开机，必须依赖功能性检测与 PM。
