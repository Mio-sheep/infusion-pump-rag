# 输液泵与注射泵：维护保养与质量控制

> 资料来源：FDA 风险控制文档、JJF 1259-2010 等公开标准信息整理
> 本文为学习整理。实际检测与维护须依据现行有效标准文本、厂家手册和本院质控规程。

## 1. 日常使用后的维护

- **清洁消毒**：严格按厂家说明书允许的清洁剂/消毒剂与方式执行。
  - FDA 明确指出：使用者认为"可以接受"的清洁方式**反而可能损坏泵**，使其在临床上不可靠。因此不要凭经验选择消毒剂。
  - 避免液体从按键缝隙渗入（FDA 报告过胰岛素泵按键间裂纹进水导致故障的案例）。
- **耗材一次性使用**：输液管路、注射器按规范一次性使用，不得复用。
- **目视检查**：每次使用前检查门体、铰链、锁扣、管路通道有无裂纹、缺口、变形。
  - 即使只有**细小的缺口或裂纹**，也应停用送修。

## 2. 电池管理

- 记录并**按推荐寿命周期更换电池**。FDA 报告过"电池未在推荐寿命终点进行例行维护更换"导致的问题。
- 关注电池外观：**鼓包、外壳接缝开裂**即为失效信号（密封铅酸电池过充损坏的典型表现）。
- 长期接市电使用不会"保养"电池；应按厂家要求进行周期性充放电维护。
- 转运前确认电量充足；必要时携带备用电源。

## 3. 预防性维护（PM）与安全检测

建议的 PM 项目（以厂家手册为准）：

| 项目 | 内容 |
| --- | --- |
| 外观与机械 | 门、锁扣、铰链、卡槽、推杆、传动机构磨损与裂纹 |
| 电气安全 | 保护接地阻抗、漏电流、绝缘（按 IEC 60601-1 / GB 9706.1 系列要求） |
| 流量准确性 | 各典型流量点的输注误差检测 |
| 报警功能 | 气泡、阻塞、电池欠压、门未关、未装注射器等报警的触发与声压 |
| 传感器 | 气泡传感器、压力传感器灵敏度与清洁度 |
| 软件/固件 | 版本核对、按厂家公告升级 |
| 电池 | 容量/续航测试，按寿命更换 |

## 4. 流量准确性的检测与校准

### 4.1 国内计量依据

- **JJF 1259-2010《医用注射泵和输液泵校准规范》**：国内对医用注射泵与输液泵进行**校准**的主要计量技术规范，用于评定流量（及流量误差、流量稳定性等）计量性能。相关计量机构与期刊文献对此规范有解读与实践建议。
- 部分省份另有地方计量规程（如 JJG(新)07-2014《输液泵/注射泵》等），使用时应确认本地区现行有效的规程版本。

### 4.2 国际/行业标准

- **IEC 60601-2-24**（对应我国 YY 9706.227 系列）：医用电气设备——输液泵和输液控制器的专用要求。规定了流量准确性、报警系统、以及**阻塞解除后团注量（bolus after occlusion release）**等关键性能的试验方法。
  - 这里需要特别注意：阻塞报警解除瞬间可能产生一次性团注，标准对可接受限度有明确要求，这直接关系到小容量、高浓度用药的安全。

### 4.3 检测方法与不确定度

- 常用方法：以分析天平称量法（重量法）测定输注质量，换算为体积流量；或用专用输液泵检测仪直接测量。
- 需记录并评定**测量不确定度**：主要来源包括天平、计时器、温度（液体密度随温度变化）、蒸发损失、管路与注射器一致性等。
- 检测应在**稳定环境温度**下、按规定预运行时间后进行，避免初始阶段的流量波动影响结果。

## 5. 结果判定与不合格处理

- 判定限值以**现行有效的标准/规程**和**厂家技术指标**为准；两者不一致时，通常以更严格者或按本院质控规程确定。
- 不合格（超差）设备应：停用 → 挂标签 → 隔离 → 报修/校准 → 复检合格后方可回临床。
- 每次 PM 与检测结果应形成**可追溯记录**（设备编号、检测日期、检测点、误差、结论、检测人、所用标准器及有效期）。

## 6. 设备台账与全生命周期管理

建议建立的记录：

1. 设备台账：型号、序列号、购置日期、启用日期、所在科室。
2. 维修记录：故障现象、报警代码、更换部件、维修人。
3. PM 记录：日期、项目、结果、下次到期日。
4. 计量校准记录：依据规程、标准器、检测点、误差、不确定度。
5. 电池更换记录。
6. 不良事件与上报记录。
7. 培训记录：操作人员培训与考核。

## 7. 常见误区

| 误区 | 正确做法 |
| --- | --- |
| 泵还能开机就说明能用 | 软件缺陷、传感器失效可能不表现为"开不了机" |
| 裂纹很小不影响使用 | FDA 明确：含细小裂纹即应停用送修 |
| 报阻塞报警一定是管路打折 | 设备本身可能**误报**阻塞；反过来说，管路阻塞时也可能**不报警** |
| 电池一直插着电就是好的 | 需按寿命更换并做容量维护 |
| 自己选消毒剂擦一擦 | 必须按厂家允许的清洁方式，否则会损坏设备 |
