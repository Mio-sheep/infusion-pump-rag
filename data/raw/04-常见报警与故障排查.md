# 输液泵与注射泵：常见报警与故障排查

> 资料来源：FDA 输液泵问题与风险控制文档整理
> 本文为学习/培训参考。**真实临床场景请遵循本院流程与厂家手册**，不可仅凭本文处置。

## 1. 排查的通用思路

1. **先看患者**：评估患者生命体征与输注必要性，必要时先夹闭管路、改用备用泵。
2. **再看屏幕**：记录完整的报警代码/文字，不要只记住"响了"。
3. **再查耗材与机械**：管路是否卡好、是否夹瘪、注射器是否装到位、门是否关严。
4. **再看电气**：电源、电池、接口是否异常（烧焦味、打火、发烫）。
5. **不能复现也要上报**：无法解释的报警即应停用、挂标签、隔离封存。

## 2. 按报警类型排查

### 2.1 气泡报警（Air-in-line）

可能原因：
- 药液袋/瓶已排空，管路内进入空气。
- 管路接头未拧紧或穿刺器未插到底。
- 加药/换袋时未彻底排气。
- 气泡传感器表面有污渍、冷凝水或安装偏位 → **误报**。

处理方向：先夹闭管路，检查液面与接头，按规范重新排气；若反复误报，检查传感器窗口是否清洁、管路是否为专用型号。

### 2.2 阻塞报警（Occlusion）

可能原因：
- 管路打折、受压（患者压住、床栏挤压）。
- 三通/夹子处于关闭状态。
- 留置针/中心静脉导管堵塞、贴壁。
- 输液器过滤器堵塞。
- **无阻塞却报警**：FDA 明确报告过"在不存在阻塞的情况下发出阻塞报警"的案例，属设备异常。

重要提示：阻塞解除的瞬间可能出现**一次性团注（bolus）**，对小容量、高浓度、血管活性药而言风险显著。解除阻塞时要结合临床评估，不要快速猛冲。

### 2.3 未装好 / 注射器相关报警

- 注射器规格与泵内设置不一致（如用 20 mL 注射器却选了 50 mL）。
- 注射器法兰未卡入夹具、推杆未顶紧活塞 → 推杆空走，实际**输注不足**。
- 注射器未预充或容量不足以完成设定输注 → 部分型号会提示"注射器内液量不足以输送设定剂量，按确认键"。
- 延长管未排气、连接松动。

### 2.4 门未关 / 门锁报警

- 管路未完全卡入固定夹就关门，门体承受应力，长期可致**门体裂纹、铰链断裂**。
- 跌落或碰撞造成的门、锁扣损坏。
- 处理方向：重新正确安装管路；若门体有裂纹或关不严，**立即停用送修**。

### 2.5 电池/电源报警

- FDA 报告：患者外出活动返回后忘记插电，泵发出低电量报警，但**扬声器音量设置过低未被察觉**，最终电池耗尽、泵自动关机。
- 电池**未按推荐寿命周期更换**。
- 设计问题导致电池**过热**，进而提前失效（可见电池鼓包、外壳开缝）。
- 电源线插拔时出现**打火、电击感**，或闻到糊味、看到火焰。

处理方向：转运前确认电量并携带备用电源；定期检查并按时更换电池；出现打火/焦痕/异味立即断电停用并上报。

### 2.6 软件类报警

- 显示软件错误信息并宣称设备不可用，但**不存在可识别的实际故障**。
- **按键连击（key bounce）**：一次按键被登记为多次，例如设定 10 mL/h 变成 100 mL/h。

处理方向：设置完成后**必须核对屏幕数值**；出现软件错误信息应记录代码、停用并上报。

## 3. 故障分级与去向

| 现象 | 建议处置 |
| --- | --- |
| 参数输入错误、单位选错 | 立即更正并复核，按制度评估患者影响 |
| 气泡/阻塞报警（有明确诱因） | 排除诱因后按规程重启输注 |
| 有明确诱因但反复报警 | 更换耗材或更换泵 |
| 无法解释的报警 | 停用、挂标签注明问题、隔离封存、上报 |
| 破损（含细小裂纹） | 停用送修，不得继续使用 |
| 打火、火花、焦痕、电击感、冒烟/起火 | 立即断电、停用、上报，必要时启动消防与安全流程 |

## 4. "停用并隔离"的判定条件（FDA）

出现以下任一情况时，应把泵从使用中移除，贴上注明具体问题和临床人员联系方式的标签并隔离：
1. 有破损迹象，**包括细小的缺口或裂纹**；
2. 发生了**无法解释的报警**；
3. 泵未按预期工作。

## 5. 易被忽视的细节

- 报警音量被调低 → 报警被漏听。
- 假报警（nuisance alarm）过多 → 使用者对所有报警的敏感度下降（"报警疲劳"）。
- 打印字符被长指甲磨掉 → 按键标识不可读。
- 用不合适的方式清洁消毒 → 反而损坏泵，使其在临床上不可靠。
