# 输液泵与注射泵：工作原理与关键部件

> 资料来源：FDA 输液泵术语表与风险控制文档、IEC 60601-2-24 / YY 9706.227 相关公开说明
> 本文为学习整理，不构成维修或临床依据。

## 1. 蠕动式输液泵的工作原理

1. 输液管路被压入泵的管路通道（tubing channel），并由管路固定夹（tube holder clips）定位。
2. 泵门关闭后，一组滚轮（rollers）或挤压指（fingers）沿管路依次挤压、释放。
3. 每次挤压把管路内的一小段液体向前推进，形成连续、近似恒定的流量。
4. 理论流量 ≈ 单次挤压排量 × 挤压频率。因此**管路的实际内径与弹性回弹**直接决定输注精度。

**要点**：蠕动泵的精度依赖"专用耗材"。使用非配套输液器会改变单次排量，导致输注误差。

## 2. 注射泵的工作原理

1. 药液装在活塞式注射器内，注射器固定在泵的卡槽中，注射器法兰（flange）被夹持固定。
2. 推杆（pusher / plunger drive）顶住活塞尾部，由步进电机驱动匀速前推。
3. 流量 = 注射器内截面积 × 推杆前进速度。因此**注射器规格（内径）必须与泵内选择的规格一致**。
4. 因为注射器内径小且刚性高，注射泵在小流量（如 0.1~10 mL/h）下精度通常优于蠕动泵。

**要点**：注射器装卡不当会造成"未装好""推杆脱开"，直接导致输注不足或延迟。

## 3. 弹性泵（非电驱动）

药液储存在可拉伸球囊中，依靠弹性膜壁的弹力提供输注动力，不需要电源。多用于一次性、便携式、固定速率的持续输注场景。其流量受温度、黏度、球囊填充量影响较大。

## 4. 关键部件与常见失效点

| 部件 | 作用 | 常见失效/风险 |
| --- | --- | --- |
| 泵门与锁扣（door & latch） | 固定管路/注射器并压紧 | 跌落损坏、管路错位导致门体裂纹、关门不到位引发阻塞或输注不足 |
| 管路通道与固定夹 | 保证管路位置正确 | 未完全卡入固定夹即关门 → 管路被夹瘪 → 输注不足 |
| 压力/阻塞传感器 | 检测管路阻力升高 | 失效时**不报警**；或**无阻塞时误报**阻塞 |
| 气泡检测器（超声） | 检测管路内空气 | 漏报气泡；或误报气泡报警 |
| 步进电机 + 传动机构 | 提供驱动力 | 磨损导致流量漂移 |
| 电池 | 断电/转运时供电 | 过充过热、老化、未按寿命更换 → 运行中关机 |
| 显示屏与按键 | 参数设置与状态显示 | 按键"连击"（key bounce）、打印磨损、界面歧义 |
| 软件/固件 | 控制流量、报警逻辑 | 软件缺陷、无故障报"设备不可用"、单位混淆 |
| 电气接口/电源线 | 供电 | 打火、烧焦、漏电电击 |

## 5. 软件与"按键连击（key bounce）"问题

FDA 报告过的典型软件问题：

- 设备显示软件错误信息并声明不可用，但**并不存在可识别的实际故障**。
- 一次按键被识别为多次按键（key bounce）。例如操作者设置 10 mL/h，设备却登记为 **100 mL/h**。

后果可能是**十倍级的过量输注**，属于严重风险。因此参数设置后必须复核屏幕显示的数值。

## 6. 人机界面（human factors）与"使用错误（use error）"

- 安全有效使用是指：使用者不因操作而受伤，并且达到预期治疗目标。若未达到，即发生了"使用错误"。
- 使用错误的根因属于**人机工程/人因（human factors）**范畴：研究人如何使用技术，涉及人的能力、预期、局限与工作环境、系统设计之间的相互作用。
- 典型设计缺陷示例：
  - 屏幕未明确标注期望输入的单位（如使用者按磅输入体重，而泵要求千克）。
  - "开始输注"键紧邻"电源"键，使用者想启动却把泵关机；部分型号关机后已设参数丢失，需重新输入。
  - 警告信息含义不清，无法判断是在确认警告还是在确认输注参数。
  - 报警功能与阈值设计不当，导致使用者漏看或反应过迟（如低电量报警提示过晚，转运途中泵突然关闭）。
  - 说明书含混、不全、过期或缺失，居家使用者尤其受影响。
